# MenuIQ Quick Start

## 1. Try the example

Open `MenuIQ.html` and choose **See an example first**. Review the Overview recommendation, then open a dish to see the explanation behind its status.

## 2. Add your own menu

Choose **Menu → Add dish** and enter:

- Dish name
- Selling price
- Ingredient cost per serving
- Units sold per month
- Optional waste units

Use the same reporting period for every dish. Monthly figures are easiest to compare.

## 3. Read the recommendation

Return to **Overview**. MenuIQ ranks dishes using the prices, costs and sales you entered. Treat the result as a practical starting point for investigation, not as a promise.

## 4. Test an idea

Open **Scenarios**, choose a dish, and adjust price, cost or units sold. The result shows the estimated monthly and annual difference from the current figures.

## 5. Protect your data

Open **Settings → Download full backup**. This creates a JSON file containing your saved MenuIQ data. Keep a copy outside the browser. Use **Restore full backup** when moving devices or recovering data.

## 6. Use CSV when needed

Use `blank-menu-template.csv` to prepare a spreadsheet. Required columns are:

```text
Dish, Selling Price, Ingredient Cost, Units Sold
```

Export CSV for spreadsheet analysis. Use the full JSON backup when you need to restore the complete app state.
